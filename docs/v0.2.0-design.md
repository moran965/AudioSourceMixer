# v0.2.0 授权、启动和安装设计说明

浏览器输出映射不是 Windows endpoint 与 Chromium deviceId 的可证明等价关系，所以 v0.2.0 将“系统选择器返回”与“正式保存”拆开。系统返回值只形成内存候选；测试音使用该候选 sink；只有用户确认物理听感后才写入 schema 3。名称匹配只负责产生提示，明显不一致要二次确认，不能替代用户判断。

空闲生命周期也明确分层：service worker 可恢复 session/offscreen 状态，但无活动图不建立 Native Messaging；Native Host 即使被浏览器启动，也只尝试现有桌面管道并退出。它没有启动桌面程序的权限或代码路径。真正的登录启动只由安装器/设置页拥有的 HKCU Run 值控制。

安装路径从静态全局量改为 `InstallOptions` 的必需值，所有快捷方式、manifest、卸载项和启动项都接受同一规范化路径。安装提交仍采用目标同卷的 staging → backup → target 移动；卸载则要求 identity 文件与卸载注册表路径共同匹配，从而不会把任意同名目录当成产品目录删除。
