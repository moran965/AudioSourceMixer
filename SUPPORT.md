# Support

Use GitHub Issues for reproducible, non-sensitive bugs and feature requests. This volunteer project does not promise response times or individual support.

Before opening an issue, update to the latest official release, read the README and user guide, and reproduce with the smallest safe configuration. Include the app version, Windows build, browser name/version when relevant, expected behavior, actual behavior, and redacted steps.

Do not post full logs, raw output-device IDs, browser profiles, page titles/URLs, credentials, user-directory paths, or other personal data. Quote only the minimal redacted log lines. Use [SECURITY.md](SECURITY.md) for vulnerabilities.
